# Fin_Trust-ML
Credit wise loan system using ML 

Built an end-to-end supervised machine learning pipeline for loan prediction.
Implemented and compared multiple machine learning algorithms, including:

Logistic Regression
K-Nearest Neighbors (KNN)
Naive Bayes

Performed Binary Classification along with:

Exploratory Data Analysis (EDA)
Feature Engineering
Data Preprocessing
Model Evaluation using Precision, Recall, and F1-Score.
